隱私政策

清楚說明手機、你選定的 Blender 主機，以及本站之間的資料流向。

ON THIS PAGE適用範圍相機與動作配對與傳輸保存與刪除你的選擇網站服務問題與更新

適用範圍與發布者

本說明涵蓋 CineRudder iOS／iPadOS App、其 Blender 主機工作流程，以及此產品網站。產品目前尚未公開下載。個人發布者為 Ian Chen；隱私聯絡方式為 ianchen.support@icloud.com。

政策版本：2026-10-30。本說明適用於目前產品與網站的資料處理方式。

相機、動作與 AR

相機可用於讀取 Blender 配對 QR Code；AR 模式在裝置上使用 ARKit 計算方向與相對位置，體感模式使用 Core Motion 提供的旋轉資料。控制姿態、可用的 AR 相對位置與搖桿輸入會傳給你選定的 Blender 主機。

現行 App 沒有把手機相機影像、相簿照片、麥克風錄音、臉部或眼部追蹤傳給發布者的功能，也不要求相簿、麥克風或 GPS 定位權限。這不代表控制資料不會離開手機。

配對與資料傳輸

App 傳送配對驗證資料、暫時控制端識別、旋轉／可用的相對位置、搖桿輸入、指令、App 內事件間的時間間隔及拍攝設定至你指定的主機；並接收主機的攝影機或物件名稱、設定、時間軸、連線狀態與預覽影像。預覽來自 Blender 場景，不是手機相機畫面。

一般配對流程使用 HTTPS 與配對碼中的精確主機憑證指紋，不會安裝系統根憑證，也不接受重新導向。現版保留明確指定本地 HTTP 網址的未加密相容流程；HTTPS 主機亦可由使用者指定，並非硬性限制在區域網路。請只連接你信任且有權使用的主機。

現行 App 與外掛沒有內建發布者雲端上傳、廣告或第三方分析 SDK，使用 App 不需要 CineRudder 帳號。你選定的主機、作業系統與額外使用的服務，其資料處理由各自的服務與設定決定。

保存與刪除

觸覺回饋與橫向版面偏好保存在 App 本機設定；控制端識別、配對 key 與掃描指紋由程序／session 記憶體管理。控制請求與影片串流停用 URL cache，控制與 H264 亦停用 cookie storage。

Blender 主機在記憶體保存連線、控制與有界樣本佇列。錄製 take 可建立 Motion 與 Optics Actions，並隨你保存的 .blend 檔持續保留。主機也保存 HTTPS 私鑰／憑證；臨時配對 QR 檔在服務停止時清理。中斷連線或移除手機 App，不會自動刪除主機檔案與 take。

診斷與你的選擇

App 顯示連線、預覽與 AR 診斷；啟用開發用方向診斷參數時，可輸出方向／幾何狀態至系統 console。外掛停用預設 HTTP request log，但作業系統仍可能產生自己的診斷。現行 App 沒有自動上傳 crash 或分析資料至發布者的 SDK。

你可在系統設定管理相機與區域網路存取。動作提示與可管理項目依 API、裝置與系統版本而定。可用性允許時，使用僅搖桿模式；在 Blender 管理保存的場景與 take。若你主動向支援提供訊息，我們僅為處理該問題使用必要內容；請勿傳送配對秘密或不必要個人資料。

此網站與外部服務

此網站由 GitHub Pages 提供靜態頁面，沒有自行加入分析、廣告、追蹤 cookies、表單後端或第三方字型。網站本身不要求登入。GitHub 作為託管服務商，可能處理 IP 位址、裝置與請求紀錄；請參閱 GitHub 隱私聲明。外部連結與電子郵件服務有各自的隱私實務。

問題與政策更新

對上述處理或你主動提供給支援的資料有疑問，請聯絡 ianchen.support@icloud.com。若產品或處理方式改變，本頁將更新版本日期與相關說明。
