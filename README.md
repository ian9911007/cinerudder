# CineRudder product website

A static Traditional Chinese product, support, privacy and open-source information site for CineRudder. The App is not yet publicly available.

Serve locally with `python3 -m http.server 8080`. The site uses plain HTML, CSS and original SVG assets with no build dependencies, analytics or external fonts. Publish the repository root through GitHub Pages from `main`.

This repository contains only public website material. It does not distribute the native App, Blender extension, private project history or signing material. The open-source page describes relevant third-party attribution; software distributions carry their own licenses.
